# 小天画布 · Product Introduction

> **AIGC Infinite Canvas** · A pure-frontend AI creative workbench

小天画布 (Xiaotian Canvas) is a one-stop AI creation platform covering **image · video · voice-over · music · storyboard · character design**. Local-first, started in one process.

Repository: https://github.com/aa309888654-lang/AIGC-Infinite-Canvas-Generation-Software

> 📖 中文版本：[`docs/产品介绍.md`](./产品介绍.md)

---

## 🎨 Core Features

### 1. AI Image Generation (Advanced)

Supports **text-to-image, image-to-image, reference, style transfer, random seed, mark control, multi-image reference** modes. Built-in mainstream models (Doubao Seedream 5.0 Lite, etc.) with adjustable 16:9 / 2K ratio and quality.

![AI Image Generation UI](./images/ai-image-ui.png)

---

### 2. AI Video Generation

Supports **text-to-video, image-to-video, first-last frame generation, first-frame generation, upload reference** modes:

- **Text-to-Video**: pure text description generates short clips
- **Image-to-Video**: single image as first frame or reference
- **First-Last Frame**: upload start/end frames, AI fills the in-between motion
- **First-Frame**: uploaded image as starting point, AI continues the action
- **Camera/Action/Light Control**: fine-grained control via `@reference` and `camera/action/light` tags
- **Video Optimization**: auto-upscale the output
- **Multi-model Support**: Hailuo and other video models; adjustable 16:9, 1080P, 6s duration

![AI Video Generation Node](./images/ai-video-ui.png)

---

### 3. Advanced Image Workflow

End-to-end pipeline: upload reference → AI enhances visual quality → switch art styles (national style / realistic / anime, etc.) → 8K high-quality output.

![Advanced Image Workflow](./images/3.png)

---

### 4. AI Voice-over + AI Music

- **AI Voice-over**: multiple voices (gentle female, magnetic male, lively girl, mature uncle, etc.), natural emotional expression
- **AI Music Generation**: diverse styles, one-click soundtrack
- **Sound Effects & Mixing**: rich sound library, professional mixing controls
- **Efficient Creation**: save time, unleash creativity

Make your work soundly moving.

![AI Voice-over and AI Music](./images/2.png)

---

### 5. Storyboard / Shot Drawing

**4-step pipeline creation**: Source material & creative intent → script generation → panel generation → shot rendering.

In a unified interface, plug in **text / visual reference / video reference / character reference**, select output style (hand-drawn storyboard / realistic storyboard / character generation / still photo), and set panel count per image (3 / 6 / 9 / 12 panels). AI auto-applies aspect ratio and output specs, generating an editable storyboard plan.

![Storyboard Creation UI](./images/storyboard-ui.png)

**Result**: a complete **shot script** for your screenplay. Each panel is annotated with **shot size (medium / wide / close-up), camera move (static / pan / slow push), emotion (curiosity-and-establish / tension-building)**, plus **director notes**. From inspiration to frame, unleash infinite creativity.

![Storyboard Panels Example](./images/图片_1784194337381.png)

---

### 6. Character Design / Asset Sheets

Build **consistent, reusable character assets** for your project:

- **Standard Views**: front / side / back
- **Expression Set**: default, calm, resolute, pensive, angry, smiling
- **Action Poses**: dynamic poses
- **Detail Showcase**: face close-up, hair structure, fabric texture, waist accessories, footwear details, weapon details
- **Color Palette**: 6-8 main colors
- **Material References**: silk, damask, metal, leather, gemstone, jade

Build once, reuse across the entire work.

![Character Design Sheet Example](./images/图片_1784194701757.png)

## 🚀 Quick Start

```bash
# Requires Node.js >= 18
git clone https://github.com/aa309888654-lang/AIGC-Infinite-Canvas-Generation-Software.git
cd AIGC-Infinite-Canvas-Generation-Software
npm install
npm run dev
# Open http://localhost:5178
```

For full deployment and API key setup, see [README.en.md](../README.en.md) and [server/README.md](../server/README.md).

## 🔧 Tech Stack

- **Frontend**: React 19 + Vite + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express + Prisma + SQLite/PostgreSQL
- **AI Model Adapters**: Doubao Seedream / SenseNova / StepFun / Agnes / MiniMax / DeepSeek / Zhipu GLM / Vidu / NVIDIA NIM
- **Infinite Canvas**: React Flow / Konva.js / Fabric.js
- **Optional Desktop Clients**: Electron / Tauri (desktop packaging)
